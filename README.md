# Learning Brief · 学习简报

给成年人的限时学习工具：把「一个知识点」或「一本书」在有限时间内压成一份**能直接用的简报**——结论先行、带出处、可导出。

> 曾用名 `socratic-tutor`。改名原因：实际行为是「讲授 + 定点检验」，不是苏格拉底诘问；新名字指向真正的交付物——一份 Brief。

## 核心特点

- **先问目的与时间**：开场 ≤2 次往返，同时问「搞懂一个点 / 吃透一本书 / 只要结论」和「5 分钟 / 30 分钟 / 不限」，未答默认 30 分钟
- **三条路径**：单点速学（1–3 模块，总往返 ≤6）／结论先行（第一屏给结论，推导进附录）／书稿吸收（一次性输出五段）
- **结论先行（BLUF）**：结论一句话 → 三条要点（≤25 字、动词开头）→ 一个带数值的例子 → 一个常见误用；取消「专业+通俗各讲一遍」
- **提问只留两处**：易混淆二选一辨析 + 段末「用你自己的话说一遍」，取消每模块「你熟不熟」问卷
- **可验证**：事实性断言带行内出处（`书名 p.123` / 链接 + 日期）；作者主张标〔作者观点〕；材料模式同样允许外部核验，标注 一致/存疑/相反，查不到写「未核实」
- **书稿吸收**：不按章节拆，输出「一句话主张 / 论证链（标最弱一步）/ 反例与边界 / 5–9 节点可迁移框架 / 3 条本周动作」，每段带可信度标注
- **三件套交付**：可粘贴 Markdown Brief 卡 + 一页框架图 + 存档（含误解清单与推导附录）；说「导出」即写入 `~/Documents/学习笔记/`
- **成年人语气**：默认「同行」档，不哄不寒暄；禁用哄娃句式；原 6 张人设卡改为「用户点名才启用」
- **隐私保护**：涉密/内部内容默认关闭联网核验，存档主题名脱敏，上传正文不入存档

## 两条主路径

```
开场（1 次往返：目的 + 时间；至多再补 1 问）
   ├─ 单点速学（1–3 模块，总往返 ≤6）
   │     查证 → BLUF 讲解 → 二选一辨析 → 一句话复述 → 交付
   ├─ 结论先行（5 分钟 / 只要结论）
   │     第一屏：结论 + 3 要点 + 数字例子 + 常见误用 → 推导进附录
   └─ 书稿吸收（一本书）
         一次性五段输出 → 只在最易误解的 2 处各问 1 道辨析题
   ↓
交付三件套（Brief 卡 + 一页框架图 + 存档）
```

共用底层能力：**定点查证与引用**、**BLUF 结构化讲解**、**两处检验**、**存档与一页图**。

## 快速开始

直接说：

- 「什么是边际成本，我 25 分钟，周会要用」
- 「帮我快速搞懂 XX，30 分钟」
- 「快速看完这本书，我要能用的框架」（附带上传文件）
- 「我只有 5 分钟，先给结论」
- 「继续学 边际成本」（恢复上次进度）

## 目录结构

```
learning-brief/
├── SKILL.md                # 主指令：路由、三条路径、规则
├── README.md               # 项目说明（本文件）
├── references/
│   ├── personas.md         # 3 个语气档 + 原 6 张人设卡（点名启用）+ 禁用句式
│   └── report-guide.md     # 一页框架图 / 可选分享卡 生成规范
└── assets/
    └── save_template.md    # 存档模板（误解清单 + 可复用资产 + 推导附录）
```

## 安装

1. 将本仓库内容复制到你所用 AI 工作台的 skills 目录，目录名必须为 `learning-brief`
2. 刷新/重启工作台，使其加载该 Skill
3. 说出学习意图（如「25 分钟搞懂 XX」）即可开始

## 数据与存档

- 学习存档：`~/.learning-brief/存档/<主题>.md`
- 一页框架图：`~/.learning-brief/存档/<主题>-框架图.png`
- 可选分享卡：`~/.learning-brief/存档/<主题>-分享卡.png`
- 导出笔记：`~/Documents/学习笔记/<YYYY-MM-DD>-<主题>.md`
- 旧版本存档路径 `~/.socratic-tutor/存档/` **只读兼容**（不自动迁移，可手动复制）

## 平台兼容性

- 不依赖任何特定 AI 平台
- 外部能力按需降级：联网检索 / 交互选项 / HTML 渲染 / 视频检索，有则用，无则退回纯文本（选择题降级为 A/B 文字作答）
- 存档路径与文件格式为跨平台通用约定

## 从 socratic-tutor 迁移

- 目录名：`socratic-tutor/` → `learning-brief/`；frontmatter `name` 同步改名
- 存档目录：`~/.socratic-tutor/存档/` → `~/.learning-brief/存档/`（旧目录保留，只读）
- 激活语「继续学 X」保持不变
