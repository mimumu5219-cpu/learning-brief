# 一页框架图与可选分享卡 生成规范

成年人场景的默认可视化交付物是**一页框架图**（用于贴进文档、截图进周会、进笔记系统）；3:4 海报降级为**可选分享卡**，仅当用户明确说要分享/发群时生成。

## 1. 触发时机

| 场景 | 默认动作 |
|---|---|
| 单点速学完成 | 生成**一页框架图** |
| 结论先行模式 | 不生成图；提供 Brief 卡文本 |
| 书稿吸收完成 | 生成**框架图**（含 5–9 节点循环/矩阵） |
| 用户暂停 | 询问「要不要生成一页框架图？」，同意才生成 |
| 用户说「发群里 / 分享 / 我要一张好看的」 | 追加生成 **3:4 分享卡** |

## 2. 一页框架图规范（默认）

### 2.1 内容（严格四部分，不加无关内容）

数据来源：刚写入的 `~/.learning-brief/存档/<主题>.md`（旧路径 `~/.socratic-tutor/存档/` 只读兼容）。**图上文字必须与存档一致**，不得改写、润色或编造。

1. **基本信息**：主题、模式（单点速学/结论先行/书稿吸收）、日期、状态（已完成/进行中）。
2. **核心结构**：5–9 个节点的循环/矩阵/层级图，每个节点一句说明书（≤20 字）。
3. **要点与误用**：3 条要点 + 1 条常见误用。
4. **状态与引用**：每个节点或模块的状态色块 + 关键断言出处（`书名 p.123` / `链接`）。

### 2.2 状态色档（4 值）

| 状态 | 颜色 | 表现 |
|---|---|---|
| 已掌握 | 绿色实心 | 实心进度条 / 绿色标签 |
| 待巩固 | 黄色 | 半实心 / 黄色标签 |
| **未验证** | **灰色虚线** | 虚线描边 + 灰字，**不画橙红、不画实心条** |
| 未讲 | 浅灰 | 空心占位 |

- 禁止把「未作答」画成橙红「需重讲」，也禁止为其填任何分数。
- 掌握度只在「≥2 次独立判断且无提示」时显示数字；否则显示「未验证」。

### 2.3 布局与尺寸

- 画幅：**横版 4:3 或方形 1:1**（便于嵌入文档与截图），不做长图。
- 布局：顶部标题区（主题 + 模式 + 日期 + 状态）→ 中部框架图（节点 + 说明书 + 状态色）→ 底部要点/误用/引用。
- 配色跟语气档弱相关，不做强绑定：
  - 同行 → 冷灰蓝
  - 教练 → 深蓝 + 高对比
  - 苏格拉底 → 米白 + 墨色
  - 其他点名人设按 `reference/personas.md` 的画像色调

## 3. 可选 3:4 分享卡

仅在用户要求分享时生成：

- 画幅 3:4，适合手机查看与转发。
- 内容 = 一句话结论 + 3 条要点 + 1 个数字例子 + 「来源见存档」。
- **不包含**模块进度表（成年人分享时不需要展示"我学到第几模块"）。
- 配色可按点名人设调整。

## 4. 生成方式

1. **首选：HTML 精确排版 → 截图/渲染为 PNG**。用 HTML/CSS 做一页框架图，所有文字取自存档真实数据，零改写。
   环境有浏览器截图或无头浏览器渲染能力时直接走这条；没有则用环境提供的 HTML→图片能力。
2. **备选：文生图**。仅当环境完全无法做 HTML 渲染时使用；必须把关键文字（主题、节点名、数字）逐字放进生成指令，生成后**逐字核对**，有误则重生成，仍错则退回纯文本 Brief 卡并说明原因。
3. 禁止交付文字出错的图。

## 5. 交付

- 图片以媒体卡片直接展示，不用普通链接。
- 文件同时存入 `~/.learning-brief/存档/`，命名 `<主题>-框架图.png`；用户要分享卡时另存 `<主题>-分享卡.png`。同名已存在 → 追加 `-v2`。
- 用户说「导出」→ 同时写入 `~/Documents/学习笔记/<YYYY-MM-DD>-<主题>.md`（图片放同目录 `assets/`）。
- 若本次是暂停后待续学：状态标「进行中」，未验证节点统一画灰色虚线，方便下次对照。
